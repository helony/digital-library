# Contributing a work to the Kurdish Digital Library

A proposed work should include, where possible:

- Exact title and author/attributed creator
- Kurdish variety and script
- Publication/composition date or best-supported estimate
- Exact source record, not only a general website homepage
- Reading/download format
- Rights evidence specific to the edition, scan or transcription
- Alternative spellings useful for search
- A short neutral description

## Rights rule

Being readable online does **not** by itself mean the library may mirror it. The underlying historical work, a modern edition, a translation, a transcription and a scan can each have different rights.

Automatic local archiving is reserved for records explicitly marked archive-eligible. Anything uncertain remains a catalogue/source link until reviewed.

## Metadata rule

Once assigned, a `KDL-...` permanent identifier is never recycled or reassigned. Corrections update the existing record rather than creating a new identity for the same edition.

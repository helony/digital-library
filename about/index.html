ABOUT THE PROJECT

A Kurdish library built to last.

The Kurdish Digital Library is an independent, preservation-first catalogue of Kurdish books and historical texts. The goal is not only to link to material elsewhere, but—where redistribution is clearly permitted—to preserve a local copy so a source disappearing does not make the work disappear from the library.

Preserve

Public-domain and clearly reusable material can be mirrored under the library’s own /books/ archive. The reader prefers the local copy when one exists.

Document

Every record keeps its original source, institution, rights note, last-check date, permanent KDL identifier, and planned local archive path.

Be careful

Access does not automatically mean permission to redistribute. Regional, uncertain, or permission-limited files remain in manual review instead of being automatically copied.

What “rights checked” means

It means the catalogue stores a source-specific rights note and a date when that information was checked. It is not a universal legal determination. Copyright can vary by edition, transcription, translation, scan and jurisdiction.

Why original sources stay visible

Even after the library stores a preservation copy, the source link stays on the record as provenance: it documents where the file or transcription came from and helps preserve attribution and context.

Permanent identifiers

Each catalogue record now has a permanent identifier such as KDL-KMR-0001. These identifiers should never be recycled, even if a title is corrected or a source URL changes.

Machine-readable catalogue

The entire catalogue is available as JSON and CSV so the metadata can survive independently of this interface and can be migrated into another library system later.
